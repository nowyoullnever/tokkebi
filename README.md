# t o k k e b i

**Status: P00.3 — renamed bootstrap with Standalone, VST3 and macOS AUv2 build targets.**

`tokkebi` is a cross-platform audio collection and sample-library product in development. P00.3 supplies only the native C++20/iPlug2 bootstrap, silent Standalone and transparent utility-plugin targets. It does not implement acquisition, persistence, preview, fonts, Helper IPC, or an end-user interface.

Repository: <https://github.com/nowyoullnever/tokkebi>
